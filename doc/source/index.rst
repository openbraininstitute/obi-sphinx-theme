OBI Sphinx Theme
================

A Sphinx theme for Open Brain Institute projects, based on
`pydata-sphinx-theme <https://pydata-sphinx-theme.readthedocs.io/>`_.

Installation
------------

.. code-block:: bash

   pip install obi-sphinx-theme

Usage
-----

In your project's ``conf.py``:

.. code-block:: python

   html_theme = "obi_sphinx_theme"

That's it. The theme inherits all features from pydata-sphinx-theme and
applies the OBI color palette (navy brand, light-blue selections,
soft blue-grey panels).

Configuration
-------------

All ``html_theme_options`` from pydata-sphinx-theme are supported.
See the `pydata-sphinx-theme docs <https://pydata-sphinx-theme.readthedocs.io/en/stable/user_guide/index.html>`_
for the full list.
